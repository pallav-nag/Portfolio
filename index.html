Scanner
Nifty 500 positional engine · point-in-time backtested
The problem

Retail swing-trading advice is untestable noise. I wanted a rules-based, interpretable scanner that ranks the Nifty 500 every evening, and, crucially, an edge I could measure against the index instead of trust on faith.

The approach

After market close it pulls NSE bhavcopy + delivery data into SQLite, computes ~15 technical / volume indicators, and scores every stock in the Nifty 500 on a single positional trend horizon (~60 trading day hold), partitioned by market-cap tier so small-caps can't swamp the list. A batched Gemini pass tags same-day news sentiment and broker calls. The composite ranks a cap-tier-partitioned, sector-capped Top-9 with disaster-stop and hold-and-rotate levels, emailed daily.

How it works
  1. Ingest: NSE bhavcopy + delivery% into SQLite via idempotent upserts (killed a real score-drift bug from duplicate rows).
  2. Score: ~15 indicators (RSI / MACD / ADX / ATR / delivery) into a single composite trend score, held ~60 trading days.
  3. News gate: Gemini tags sentiment & events; the event study found no market-neutral edge, so it's a downside-only gate, not an overfit weight.
  4. Rank: delivery-floor qualification (45%), cap-tier-partitioned sector-capped Top-9, disaster-stop + hold-and-rotate levels.
  5. Prove it: point-in-time backtest (IC, matched-window alpha) + a live ledger grading every pick vs Nifty 500.

Optimal Code Review
Agent Pipeline
Multi-agent system · Graphify-powered context retrieval
The problem

LLM code review gets expensive fast: feeding whole files into every agent burns tokens and dilutes signal, so reviews run slow, cost too much, and still miss cross-file context.

The approach

A GitHub PR review pipeline powered by specialised agents (Static Analyser, LLM Reviewer, Test Suggester) that coordinate via Redis and report through a Critic/Scorer. The key insight: agents query a graph.json via Graphify MCP instead of loading full files, cutting context by 85%.

Architecture
GitHub PR → Webhook → API Gateway → Redis Queue                                       ↓      Static Analysis ◆ LLM Review ◆ Test Suggester                                       ↓                   Aggregator → Critic / Scorer                                       ↓                  GitHub PR Comment
How it works
  1. Static Analyser: lint, complexity & security signals at zero LLM cost.
  2. LLM Reviewer: reasons over the graph subcontext, not raw files.
  3. Test Suggester: proposes the tests a change should ship with.
  4. Aggregator → Critic / Scorer: dedupes, ranks by confidence, drops noise.
  5. Single PR comment: one structured, prioritised review back on the pull request.
